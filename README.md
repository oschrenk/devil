# Devil

An iPhone app for one coffee recipe.
The recipe brews on a Hario Switch.
It blends tap and demineralized water for the mineral profile.
It also cools the bed mid-brew with a room-temperature pour.

`RECIPE.md` holds the recipe.
The recipe is fussy and carries a lot of numbers.
Every number moves when you brew for two people instead of one.
The app holds those numbers and moves them together.

## Status

Scaffolding, and one screen that proves it works.
The recipe model, the scaling and the timer still need work.
